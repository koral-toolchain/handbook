# Handbook maintenance

- Write organization documentation and visible repository content in English.
- Preserve the distinction between observed behavior, proposed support and implemented enforcement.
- The sole human maintainer is tidemark-labs. Do not invite collaborators, publish repositories or buy plans without an explicit owner decision.
- Make policy changes in the guide, JSON configuration, checker and tests together. Tests must demonstrate acceptance and rejection rather than simply repeat the guide.
- Do not claim that pin checks prove runtime compatibility or that a CODEOWNERS file alone prevents merges.
- Never copy credentials, private company implementation or compiler binaries into this repository.
- Product source upload, release publication and website deployment are separate actions.
